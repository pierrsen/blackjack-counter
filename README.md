# Blackjack Counter

Mobile-first PWA for blackjack shoe tracking, true count, and strategy deviation analysis.

**Status:** Early scaffold — UI and counting engine not implemented yet.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run lint` | Run ESLint |
| `npx tsc --noEmit` | Typecheck |
